# Legion Fill: плагин для Photoshop

Инпейнт и аутпейнт в Photoshop на Mac через ComfyUI на Legion. Модель — **FLUX.1 Fill [dev]**, она уже стоит на Legion. Всё считается локально и бесплатно.

## Как это работает

1. Плагин берёт выделенную область вместе с запасом контекста вокруг и её маску.
2. Отправляет их в ComfyUI на Legion. Там FLUX Fill перерисовывает область примерно на 1 МП.
3. Результат возвращается **новым слоем с маской** точно на место. Исходные слои не меняются, неудачный вариант достаточно удалить.

- **Инпейнт.** Выделите любым инструментом (лассо, быстрая маска, растушёвка учитывается), напишите промпт и нажмите «Сгенерировать».
- **Аутпейнт.** Укажите, сколько пикселей добавить с каждой стороны. Плагин сам расширит холст, выделит новую область с нахлёстом на исходник и дорисует её.

Есть два варианта:

- **Скрипт `jsx/Legion Fill.jsx`.** Работает в любом Photoshop, начиная с CS6. Не нужны ни Creative Cloud, ни установщик. Запускается горячей клавишей, как Generative Fill. Подходит, если у вас нет CC.
- **Плагин UXP (панель).** Нужен Photoshop 2023+ и UXP Developer Tool, который ставится через Creative Cloud.

Оба варианта используют одинаковый граф на Legion и дают одинаковый результат.

> Заменить кнопку Generative Fill в контекстной панели (Contextual Task Bar) нельзя: она встроена в Photoshop, и ни плагины, ни скрипты не могут её изменить. Ближайший аналог — выделить область и нажать свою горячую клавишу.

## 1. Подготовка Legion (один раз)

ComfyUI должен принимать запросы из сети, а не только с самого Legion:

```
python main.py --listen 0.0.0.0 --port 8188
```

В ComfyUI Desktop то же самое делается в Settings → Server-Config → Listen = `0.0.0.0`.

- В брандмауэре Windows разрешите входящие подключения на порт **8188** для частной сети. Можно ограничить доступ IP-адресом Мака.
- Мак и Legion должны быть в одной сети. Вне дома подойдёт Tailscale: используйте адрес Legion вида `100.x.x.x`.
- Проверка с Мака: `curl http://<IP-Legion>:8188/system_stats` должен вернуть JSON.

## 2а. Скрипт .jsx: без Creative Cloud

1. Скопируйте `jsx/Legion Fill.jsx` в `/Applications/Adobe Photoshop <версия>/Presets/Scripts/` и перезапустите Photoshop.
   Без копирования скрипт можно запустить разово через File → Scripts → Browse…
2. Назначьте клавишу: Edit → Keyboard Shortcuts → Shortcuts For: Application Menus → File → Scripts → **Legion Fill**, например ⌘⇧G.
3. Выделите область и нажмите клавишу. Откроется окно, в котором нужно ввести промпт и нажать Enter. При первом запуске впишите адрес Legion в «Сервер ComfyUI» и нажмите «Проверить».

Как это работает:
- **Отмена.** Пока идёт генерация, Photoshop занят. Esc или кнопка «Стоп» останавливают задачу на Legion.
- **История.** Вся операция — один шаг истории, Cmd+Z отменяет всё сразу. Если аутпейнт прервётся, холст вернётся к прежнему размеру.
- **Настройки** сохраняются в `~/Library/Application Support/LegionFill/settings.json`.
- **Связь с Legion** идёт через системный `curl` из macOS.

## 2б. Плагин UXP: нужен Creative Cloud

Нужен Photoshop 2023 (24.2) или новее.

**Через UXP Developer Tool** (надёжный способ):

1. Установите **UXP Developer Tool** из Creative Cloud (раздел «Все приложения» → «Разработка»).
2. Нажмите Add Plugin и выберите `tools/ps-legion-fill/manifest.json`.
3. Нажмите ••• → Load. Панель появится в меню Плагины → Legion Fill.
4. Чтобы плагин оставался после перезапуска Photoshop, в UDT выполните ••• → Package. Получится файл `.ccx`, установите его двойным щелчком.

**Быстрый вариант:** `./build.sh` собирает `legion-fill.ccx`, его можно установить двойным щелчком. Если Creative Cloud откажется ставить неподписанный пакет, используйте UDT.

## 3. Параметры панели

| Поле | По умолчанию | Что делает |
|---|---|---|
| Сервер | — | `http://<IP-Legion>:8188`. Кнопка «Проверить» показывает версию ComfyUI и свободную VRAM |
| Промпт | пусто | Что должно появиться. Если оставить пустым, область дорисуется по контексту |
| Шаги | 24 | 20–30 — нормальный диапазон для FLUX Fill |
| Guidance | 30 | Для Fill-модели рекомендуется высокое значение, 30 — официальная настройка |
| Варианты | 1 | До 4 вариантов за проход. Каждый становится отдельным слоем, видим последний |
| Сид | -1 | -1 — случайный. Сид пишется в имя слоя, удачный результат можно повторить |
| Мегапиксели | 1.0 | Рабочее разрешение генерации. Результат масштабируется обратно в размер области |
| Контекст | 40 % | Сколько окружения вокруг выделения видит модель |
| Растушёвка | 12 px | Мягкость края маски слоя, чтобы не было шва |
| FP8 | выкл | Веса в FP8: быстрее и меньше VRAM, качество чуть ниже |
| Нахлёст (аутпейнт) | 32 px | Насколько новая область заходит на исходник, чтобы скрыть шов |

## Советы

- Для больших выделений (больше ~2000 px) поднимите «Мегапиксели» до 1.5–2. Иначе мелкие детали получатся мягче остального снимка.
- При аутпейнте больше чем на 50 % лучше расширять в несколько проходов, по одной стороне.
- После генерации исходное выделение остаётся активным. Можно сразу нажать ещё раз и получить новый вариант.
- Файлы сохраняются и на Legion: `output/photoshop/fill_000NN_.png`.

## Файлы

- `jsx/Legion Fill.jsx` — версия-скрипт: всё в одном файле, работает без CC.
- `manifest.json`, `index.html` — описание панели UXP и её интерфейс.
- `main.js` — логика панели.
- `js/ps.js` — работа с Photoshop: выделение, холст, пиксели, размещение слоя.
- `js/comfy.js` — клиент HTTP/WebSocket для ComfyUI.
- `js/workflow.js` — граф FLUX Fill.
- `js/png.js` — кодировщик PNG без зависимостей.
